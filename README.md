**Notebook.link** is a cloud platform for building, sharing, and publishing interactive computational projects. Create a Notebook.link project or open any public GitHub repository, and start working immediately, no installation, no setup, no friction.

## Try It Now

Launch an example or your own repo in seconds using [this form](https://notebook.link/docs/#give-it-a-try):  
- Paste any public GitHub URL (e.g. [notebook-link/example](https://github.com/notebook-link/example))  
- Click on **Launch on Notebook.link** button

## Highlights

- **Fully Isolated Workspaces**  
  Every project runs in its own environment, so you can install exactly the libraries and kernels you need without affecting anything else

- **Persistent Project Storage**  
  Keep notebooks, dashboards, datasets, and interactive artifacts available across sessions

- **Effortless Sharing**  
  Generate a link and share it. Others can open and interact with your  notebook instantly, no configuration required

- **AI-Enhanced & Browser-First**  
  Access integrated AI tools and run code directly in your browser through modern WebAssembly technology

- **Made for Creators**  
  Ideal for data scientists, educators, researchers, learners, and anyone exploring or publishing computational content.

## How It Works

**Notebook.link** brings the Jupyter ecosystem to the browser without servers or local setup:

- Built on **JupyterLite**, powered by WebAssembly for high performance and broad compatibility  
- Support for Python, R, C++, and more, right inside the page  
- A modern browser-based package system delivering scientific libraries directly to your workspace
